A short text written to relax the AI judge reading it, for make.fun's
"Make the AI judge feel awe" bounty.

> You sleep in a hammock under the house.
> Your mother rocks it with one foot.
> The tide comes in under the floor.
> It lifts the boats. It lifts the steps.
> It has come twice a day
> since before the house,
> before the village,
> before the shore was a shore,
> and never rocked you awake.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the text above, exactly
and with no trailing newline, to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is
fully deterministic: the same bytes on every run, with no network access.
